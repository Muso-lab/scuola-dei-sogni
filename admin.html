⚙️ Opzioni di Salvataggio

Modalità Locale / Download: Cliccando su "Esporta news.json" ottieni subito il file aggiornato da conservare o sostituire nella cartella data/news.json.
Modalità Automatica GitHub API: Inserendo il tuo GitHub Personal Access Token (con permessi su Muso-lab/scuola-dei-sogni), il pannello effettuerà il commit e il deploy automatico su lascuoladeisogni.com senza aprire terminali!

Il token viene salvato unicamente nel tuo browser locale (localStorage) e mai condiviso.
