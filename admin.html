⚙️ Configura Pubblicazione Automatica GitHub

Collega il tuo GitHub Personal Access Token per pubblicare news sul sito con 1 solo click senza terminale.

📖 Istruzioni Rapide (1 minuto)

  1. Accedi al tuo account GitHub Muso-lab e apri: github.com/settings/tokens.
  2. Clicca su "Generate new token" ➔ "Generate new token (classic)".
  3. Inserisci una nota (es. Scuola dei Sogni CMS) e metti la spunta solo sul permesso repo.
  4. Clicca sul pulsante verde "Generate token" in fondo alla pagina e copia la stringa generata (inizia con ghp_...).
  5. Incolla il token nel riquadro sottostante e premi "Salva & Connetti". Fatto!
Il token rimane memorizzato esclusivamente sul tuo dispositivo locale in sicurezza (localStorage) e non transita mai su server terzi.
